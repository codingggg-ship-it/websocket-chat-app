# WebSocket Chat App

A basic real-time chat application built while following a Node.js and Socket.IO learning tutorial.

## Features

- Real-time messaging
- Multiple clients can communicate simultaneously
- Socket.IO event-based communication
- Messages broadcast to connected clients

## Tech Stack

- Node.js
- Express.js
- Socket.IO
- HTML
- JavaScript

## Learning Project

This project was built while following a tutorial as part of my Node.js/backend learning journey.

The purpose of this project was to understand the fundamentals of WebSockets, real-time communication, and Socket.IO.
